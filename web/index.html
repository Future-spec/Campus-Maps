How to explain it

Graph: locations are vertices; corridors are weighted edges. A corridor is stored in both directions.

Adjacency list: every location stores only its neighbours, which is good for a sparse campus map.

BFS: uses a queue and finds the fewest stops. Dijkstra: finds the lowest distance. DFS: goes deep, then backtracks.

Accessibility: wheelchair mode filters out stair edges before an algorithm visits them.
