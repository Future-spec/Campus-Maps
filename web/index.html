Explain this to the teacher

Graph: each room is a vertex. Each corridor is a bidirectional weighted edge stored twice in an adjacency list.

Filter, don’t rebuild: stairs / narrow / lift / blocked flags live on edges. BFS, DFS and Dijkstra skip an edge if it fails the profile.

BFS uses a queue, so the first time we reach the destination we have the fewest stops — not necessarily the fewest metres.

Dijkstra uses a min-heap on distance, so it returns the shortest walk.

DFS goes deep, then backtracks (un-visits) to list alternative routes.

Unreachable is BFS reachability: anything never enqueued cannot be accessed under the current constraints.

Console version for the lab: compile g++ -std=c++17 main.cpp graph.cpp -o campus_route_finder
